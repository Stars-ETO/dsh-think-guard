# dsh-think-guard

[English](README.en.md) | 简体中文

作者：**Wesley.T** · 许可证：[MIT](LICENSE)

DeepSeek Harness（DSH）的独立监察插件，使用单独配置的模型检查主 Agent 的执行过程和最终回复，并可在启用建议模式时提出纠正建议。

## 功能

- **观察与建议**：观察模式只记录；建议模式可将有依据的建议加入主会话。建议被取出不代表已被采纳。
- **审批**：可选择交给系统、由用户审批、自动审批或完全自主审核；按常规／高频档位筛选。只有被 DSH 钩子捕获且命中规则的操作会被审查，不能代替沙箱或保证覆盖所有操作。
- **输出后复查**：在主 Agent 准备结束当前轮时检查最终回复，包括问答、方案和项目交付。可选自动迭代，有次数上限。
- **独立监察聊天**：可选择或粘贴图片；发送后图片会显示在聊天记录中，针对图片继续追问时会再次提供给模型（可能产生额外费用）。普通聊天不会自动写入主会话。明确要求转交时，插件会尝试注入并报告状态。
- **文件检查**：按需只读工作区内的文本、PDF、DOCX、PPTX、XLSX 和图片；工作区外的路径及指向工作区外的链接会被拒绝。图片需要模型和服务商支持。
- **常规／细致检查**：细致模式提高预算并分段检查较长文档文字，会增加调用和费用，与审批频率独立。

## 安装

从 npm 安装（按实际使用的 DSH profile 调整 `desktop`）：

```sh
dsh plugin --profile desktop add dsh-think-guard
```

从 GitHub 源码安装（将 `desktop` 换成实际使用的 profile；此安装方式尚待在干净 DSH 环境中验证）：

```sh
dsh plugin --profile desktop add github:Stars-ETO/dsh-think-guard
```

本项目是 DSH 插件，不是独立程序。准备好支持插件的 DSH 和模型服务，在 DSH 插件界面添加此插件目录或从发行包安装；不同 DSH 版本的安装方式可能不同。安装后按提示重新加载插件或重启，在会话标题栏打开“思考监督”。

源码包包含 `package.json`、`cordis.patch.yml`、`lib/` 与 `vendor/`，需保持目录结构。通过本地目录链接安装时，可在 DSH desktop profile 中使用 `pnpm add "link:<插件目录绝对路径>"`，并将 `dsh-think-guard` 加入 profile 的 bundle 配置；具体配置以对应 DSH 版本为准。

本地开发测试使用 Node.js 20.19 或更高版本：

```sh
npm test
```

测试使用合成输入与模拟模型，不代表已验证所有 DSH 版本或真实模型服务。当前代码按 DSH 0.2.2-rc.1 的接口实现，其他版本需要验证。界面以中文为主，英文 README 不代表界面已完整英文化。

## 使用与限制

1. 在目标会话开启监督，选择监察模型与观察／建议模式。监察聊天可通过输入路径请求检查工作区文件。
2. 图片每次最多 3 张，上传图片每张不超过 4 MB。图片需要模型声明支持图像输入；失败时会提示未检查，并尝试继续检查已提取的文字。
3. 文档提取和模型输入有大小、页数、内容及超时限制。细致模式的分段摘要也可能遗漏细节；未提供或未读到的内容不能当作已检查。PDF 提取文字和部分嵌入位图，并非完整页面渲染；Office 原生图表、版面和部分媒体可能未被检查。
4. 完全自主审核可能接管能与当前工具调用准确关联的单次沙箱提权请求。单次完整权限允许该次调用访问整个主机，不局限于某个文件；模型判断可能出错，其他系统或插件的拒绝仍然有效。

## 隐私与数据

主会话的部分快照、指定的文件内容、图片和工具调用信息可能发送给所选模型服务商，并产生费用。DSH 附件服务可能保存图片副本。监察聊天历史只保存图片附件引用；清空监察聊天会移除引用，但不会删除 DSH 附件缓存。监察聊天和要求按会话保存在 `DSH_HOME/think-guard/memory`（默认 `~/.dsh/think-guard/memory`），可能有敏感信息；公开仓库与发行包不应包含该目录。清空界面记录不等同于撤销已经执行的操作。
